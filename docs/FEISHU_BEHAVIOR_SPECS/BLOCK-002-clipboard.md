# BLOCK-002 / 块菜单剪贴板反馈

## 交互合同

- 剪切和复制执行后检查浏览器返回值，不显示无依据的成功状态。
- 复制成功给出简短反馈；失败时提示用户使用系统快捷键重试。
- “复制文档链接”使用 Clipboard API；权限拒绝时提示从地址栏手动复制。
- 未接入翻译服务前不展示“翻译”入口，避免把复制文本伪装成翻译能力。

## 当前边界

- 富文本剪贴板仍依赖浏览器 `execCommand` 以保留编辑器选择和 HTML；后续可在浏览器覆盖允许时迁移到 Async Clipboard API。
- 对齐、颜色和下方添加子菜单的完整键盘路径由 BLOCK-003 继续实现。

## 自动化

- Client TypeScript production build。
- 后续增加剪贴板允许/拒绝两种浏览器 E2E。
