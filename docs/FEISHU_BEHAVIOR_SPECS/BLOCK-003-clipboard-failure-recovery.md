# BLOCK-003 剪贴板失败恢复

## 用户目标

用户从块菜单剪切、复制或复制块链接时，即使浏览器拒绝剪贴板权限，也不会看到误报成功或无响应。

## 行为契约

1. 剪切与复制命令返回 `false` 或抛出异常时关闭菜单，并分别提示使用 `Ctrl+X` 或 `Ctrl+C` 重试。
2. 复制块链接优先使用异步剪贴板 API；权限被拒绝时尝试浏览器选择复制后备路径。
3. 两条复制路径都失败时不显示成功提示，改为提示用户从地址栏复制链接。
4. 后备复制结束后恢复此前焦点，避免临时文本域抢走编辑器焦点。
5. 文档列表复制链接沿用同一失败恢复逻辑，不产生未处理 Promise。
6. 普通文本、图片、表格、多维表格、公式和文件块使用同一成功判定，不因入口不同而静默失败或误报成功。

## 自动化证据

- `client/tests/block-color.spec.ts` 在真实 DOM 契约中拒绝异步剪贴板权限并令 `execCommand` 返回失败，覆盖块菜单剪切、复制和块链接三类可执行提示。
