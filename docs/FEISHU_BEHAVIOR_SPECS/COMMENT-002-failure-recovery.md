# COMMENT-002 评论失败恢复

## 用户目标

评论创建、回复、编辑或解决失败时，用户输入不能消失，也不能只看到短暂的全局提示。失败应停留在对应线程内，并允许从原位置重试。

## 交互合同

- 创建或回复提交期间禁用重复提交，按钮显示“发送中…”。
- 失败后编辑器保持打开，草稿内容不变，显示“发送失败，草稿已保留”和“重试”。
- 修改草稿后清除旧错误，下一次提交使用新内容。
- 编辑评论失败时保留编辑稿，保存按钮变为“重试”。
- 解决状态更新失败时线程仍保持未解决，并在卡片内提供重试。
- 取消回复仅关闭编辑器，不删除按线程保存的草稿。
- 没有真实上传、持久化和失败恢复链路前，不显示评论附件按钮。

## 自动化

- `comment-threads.spec.ts` 覆盖首次 POST 失败、草稿保留及第二次重试成功。
- Client build 覆盖创建、编辑、解决状态类型和组件契约。
