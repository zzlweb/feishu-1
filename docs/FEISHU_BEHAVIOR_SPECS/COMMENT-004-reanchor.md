# COMMENT-004 / 丢失锚点重新关联

## 用户目标

正文删除了原评论位置后，保留讨论内容，并把整条评论线程关联到新的文本位置。

## 交互合同

- 原锚点消失后评论卡片保持可见，并明确标记“原评论位置已被删除”。
- 用户先在正文选择新的非空文本，再点击“关联到当前选区”。
- 未选择正文文本时不修改评论，并提示先选择新的评论位置。
- 成功后沿用原 thread id，恢复正文高亮及定位链接。
- 线程内所有评论统一更新 block id、文本位置、引用、锚点快照和状态。
- 更新失败时保留评论内容并提示重试，不静默删除线程。

## 自动化

- `comment-threads.spec.ts` 覆盖删除原锚点、保留线程、选择新文本并恢复关联。
