# DOC-003 / 文档保存队列与版本冲突

## 用户目标

持续编辑时内容按顺序保存；多个窗口编辑同一文档时，不允许旧版本静默覆盖新版本。

## 数据合同

- 每个文档返回 `version` 与 `schema_version`，旧 JSON 数据自动迁移为 `1`。
- 更新请求携带 `base_version`。
- 更新成功后服务端原子递增 `version`。
- `base_version` 与当前版本不一致时返回 HTTP 409，并附当前服务端文档快照。

## 交互合同

- 连续产生的修改先合并为 pending patch，再串行发送。
- 保存过程中产生的新修改留在下一批，不被旧响应覆盖。
- 网络错误保留 pending patch，页头持续显示失败并提供点击重试。
- 版本冲突停止自动重试，页头持续显示冲突；用户点击后重新加载服务端版本。
- 路由快速切换时，较早文档的迟到响应不得覆盖当前文档。

## 当前边界
