# DOC-004 本地草稿恢复

## 用户目标

网络失败、页面关闭或请求被浏览器终止时，已经输入的标题和正文不能丢失。重新打开同一文档后应恢复较新的本地内容，并由用户选择立即保存或放弃。

## 数据合同

- 草稿按文档 ID 隔离，键名带版本前缀。
- 只保存允许的文档 patch 字段、服务端基础版本、草稿时间和 schema 版本。
- 每次排队保存前同步写入本地草稿；失败时合并请求中和后续输入的 patch。
- 服务端成功且没有更新的待处理内容后才删除本地草稿。
- 损坏、超过大小限制、属于其它文档或不比服务端新的草稿不会恢复。
- 只读文档不恢复本地编辑草稿。

## 交互合同

- 打开文档时自动将较新的本地草稿回灌到编辑器。
- 页面显示“已恢复一份尚未上传的本地草稿”。
- “立即保存”进入现有版本化保存队列；“放弃草稿”清理本地记录并重新挂载服务端正文。
- 恢复后继续输入时，新输入与旧草稿合并，不会被旧内容覆盖。

## 自动化

- `documentDraft.test.ts` 覆盖版本化存取、损坏数据和新旧判断。
- `document-draft-recovery.spec.ts` 覆盖恢复后保存清理及放弃恢复服务端正文。
