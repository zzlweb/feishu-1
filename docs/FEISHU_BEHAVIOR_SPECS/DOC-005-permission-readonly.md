# DOC-005：权限只读与阅读模式

## 行为契约

1. 服务端 `read_only=1` 是不可由客户端解除的权限边界。
2. 用户主动进入阅读模式只改变本地显示状态，可以再次返回编辑模式。
3. 权限只读时页头显示“只读”，模式按钮禁用并解释原因。
4. 权限只读同时传入 Editor 和所有 Bitable 视图，不能只锁正文。
5. 只读状态仍允许查看、滚动和切换 Bitable 视图，但不能修改数据或视图配置。
6. 没有真实实现的置顶、通知、共享列表等入口不展示。

## 自动化

- `document-shell-ux.spec.ts` 覆盖阅读模式切换、权限只读不可解除、正文锁定与 Grid 写入口禁用。
