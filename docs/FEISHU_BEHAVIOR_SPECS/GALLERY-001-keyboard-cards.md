# GALLERY-001：画册卡片键盘交互

## 目标

画册卡片不能依赖鼠标点击。键盘用户应能定位卡片、打开记录，并完成单选切换与范围选择。

## 行为契约

1. 每张可见卡片都是稳定的 Tab 停靠点，并暴露 `button` 与 `aria-pressed` 语义。
2. 聚焦卡片时显示不依赖颜色填充的双层焦点轮廓。
3. `Enter` 使用与普通点击相同的路径打开记录详情。
4. `Space` 只切换当前卡片选择状态，不打开详情。
5. `Shift+Space` 从最近的选择锚点扩展连续范围，不打开详情。
6. 卡片内的删除按钮保持独立键盘行为，不触发卡片快捷键。

## 验证

- [bitable-gallery.spec.ts](../../client/tests/bitable-gallery.spec.ts) 覆盖聚焦、语义、详情打开、切换选择与范围选择。
