# GRID-001 / 多维表格只读权限

## 用户目标

只读文档中的多维表格可以浏览，但任何字段、记录、视图配置和拖放操作都不能修改文档数据。

## 交互合同

- 文档编辑器进入只读后，当前多维表格视图按锁定状态渲染。
- 单元格编辑、新增/删除记录、字段配置、筛选/排序/分组配置和拖放写入全部禁用。
- 用户仍可切换已有视图；切换只保存在当前组件状态，不更新文档 `data-model`。
- 文档恢复可编辑后，回到文档持久化的 active view，后续修改正常保存。

## 防御边界

- 交互层使用有效 `locked` 状态隐藏或禁用写入口。
- 统一 `commit` 层再次检查文档可编辑状态，防止遗漏的点击、拖放或子组件回调写入。
- 旧节点首次模型迁移仍可执行，以保证可渲染；迁移不代表用户编辑授权。

## 自动化
