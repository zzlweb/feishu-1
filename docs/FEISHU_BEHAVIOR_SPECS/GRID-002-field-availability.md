# GRID-002：字段类型可用性

## 原则

- 字段选择器不能把仅有图标或文本兜底的类型伪装为完整能力。
- 已有历史数据中的未知或暂不支持字段必须继续安全展示，不能因创建入口收敛而丢失。

## 当前可创建

- 文本、单选、多选、日期、附件、数字、复选框、超链接、电话号码、Email。

## 当前不可创建

- 人员、公式、查找引用、双向关联。
- 创建人、修改人、创建时间、最后更新时间等系统字段。

上述类型仍出现在搜索结果中，但按钮禁用、显示“待支持”，并通过 title 解释尚未具备完整数据语义。

## 防御层

1. Picker 使用原生 `disabled` 与 `aria-disabled` 阻止鼠标和键盘选择。
2. 字段表单拒绝把不可创建类型切为当前类型或提交。
3. Bitable 创建命令再次校验，阻止伪造组件输入绕过界面。
4. 旧字段模型不做破坏性迁移，读取和只读渲染保持兼容。

## 自动化

- `bitableFieldTypes.test.ts` 验证可创建矩阵、不可创建原因与搜索标记。
- `bitable-grid.spec.ts` 验证 picker 禁用语义、提示文案和推荐入口收敛。
