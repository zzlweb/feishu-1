# GRID-004：字段删除影响确认与迁移

## 触发条件

- 主字段和表格唯一字段不可删除。
- 其它字段从 Grid、Gallery 或 Kanban 字段菜单删除时，统一进入影响确认，不再调用浏览器原生确认框。

## 影响清单

删除前统计并展示：

- 包含非空字段值的记录数量。
- 筛选与排序规则数量。
- Grid、Gallery、Kanban 的分组引用。
- 标题、封面、可见字段、层级关系和 Gantt 日期等视图配置引用。

## 迁移规则

1. 只能迁移到相同字段类型。
2. 单选/多选还要求目标字段包含源字段使用的全部 choice ID，避免值变成未知选项。
3. 迁移时，源字段非空值覆盖目标字段对应记录值。
4. 兼容的筛选、排序、分组、标题、封面与日期引用同步改指向目标字段。
5. 字段顺序和隐藏状态移除被删除字段，不产生重复引用。

## 不迁移删除

- 用户明确选择“删除并清空”后，移除字段值及所有引用。
- 删除命令保证不留下引用不存在字段 ID 的规则或视图配置。

## 自动化

- `bitableModel.test.ts`：影响计数、兼容目标、迁移值与引用、无迁移清理。
- `bitable-grid.spec.ts`：取消不删除、影响文案、选择目标字段、迁移并保存。
