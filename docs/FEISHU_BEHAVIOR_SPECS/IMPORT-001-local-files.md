# IMPORT-001 / 本地文档导入

## 用户目标

把本地 Markdown、HTML、文本或飞书导出 ZIP 转成可继续编辑的在线文档，并明确告知不能还原的内容。

## 交互合同

- 文件选择和拖放走同一导入流程。
- 上传期间展示文件名和真实上传进度；上传结束后提示正在解析。
- 用户可取消上传；关闭页面时中止仍在进行的文件或链接导入。
- 成功后先展示导入质量、资源数、警告和未支持块，再由用户打开文档。
- 失败不创建空白文档，也不把取消显示成错误。

## 解析合同

- Markdown 使用 GFM，保留标题、段落、引用、列表、任务列表、表格、代码块与安全链接；front matter 的 `title` 优先作为文档标题。
- HTML 和 Markdown 渲染结果进入同一安全清洗、表格/任务列表/图片归一化流程。
- CSV 首行作为表头；TXT/LOG 保留段落与换行。
- ZIP 自动选择正文，按相对路径恢复白名单资源；缺失图片在正文原位置显示可见提示。
- 所有本地导入结果均为可编辑副本，不声称恢复飞书权限或评论线程。

## 安全合同

- 移除脚本、iframe、object、表单等主动元素，以及事件属性、危险 URL 和危险 CSS。
- SVG 主动内容不从 ZIP 恢复到静态资源目录。
- ZIP 最多 2,000 项、总展开 100MB、单项 25MB、压缩比 100；路径穿越和重复归一化路径会被拒绝。
- 单个正文最多 10MB。

## 当前边界

- 不恢复飞书私有 block、权限和评论。
- 独立 Markdown/HTML 引用的本地图片必须与正文一起打包为 ZIP 才能恢复。
- 公开链接导入的逐跳 SSRF 防护和服务端取消清理仍是后续安全任务。

## 自动化

- `server/tests/api.test.ts`：ZIP 图片恢复、Markdown 结构与主动内容清洗、异常压缩比拒绝。
- Client/Server production build 与 Client unit suite。
- 后续补充浏览器导入进度、取消和结果对话框 E2E。
