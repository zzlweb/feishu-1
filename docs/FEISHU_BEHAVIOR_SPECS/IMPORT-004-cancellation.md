# IMPORT-004 / 导入取消与恢复

## 用户目标

开始导入大文件或飞书链接后可以安全取消，并能立即重新发起一次新的导入。

## 交互合同

- 本地文件上传期间展示文件名和进度；点击“取消导入”后进度对话框立即关闭。
- 取消不打开结果页、不跳转到文档，也不显示成失败。
- 飞书 URL 导入期间锁定链接和“同时保存为模板”选项，Enter 不会重复提交。
- 关闭飞书导入对话框会 abort 当前请求，并清空 URL、结果和模板选项。
- 取消后的上传入口与飞书导入入口均可立即再次使用。
- 页面卸载会 abort 尚未完成的本地文件与 URL 导入。

## 当前边界

- 浏览器 abort 能停止继续等待响应，但服务端已经开始的解析是否中断取决于服务端任务生命周期。
- 服务端临时资源归属与断连清理归入 FG-039，不在本交互合同内伪装为已完成。

## 自动化

- `document-import-cancel.spec.ts` 覆盖本地文件取消、界面即时恢复及再次导入成功。
- 同一套浏览器契约覆盖 URL 重复提交阻断、关闭取消和再次导入成功。
