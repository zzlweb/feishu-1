# KANBAN-003：删除分组影响确认与迁移

## 行为契约

1. 删除单选分组前展示受影响记录、筛选和看板配置数量。
2. 用户可以选择同一字段中的其他分组作为迁移目标。
3. 迁移删除会把旧名称和旧 choice ID 数据统一写为目标 choice ID。
4. 相关筛选、分组顺序、隐藏分组和空分组配置同步迁移并去重。
5. 不迁移时明确清空相关记录值并移除悬空筛选和配置引用。
6. 取消、关闭或点击遮罩均不修改字段、记录或视图。
7. 至少保留一个分组选项，最后一个分组不能删除。

## 自动化

- `bitableModel.test.ts` 覆盖影响分析、迁移与无迁移清理。
- `bitable-kanban.spec.ts` 覆盖取消保护、影响提示和迁移保存请求。
