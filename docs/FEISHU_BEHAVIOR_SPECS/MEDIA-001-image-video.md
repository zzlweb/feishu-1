# MEDIA-001 图片与视频交互

## 参照

- 飞书帮助中心《在文档中插入图片》（2026-04-15 页面版本）：图片悬浮显示工具栏；裁剪通过可拖动边界完成；图片说明支持 `Shift+Enter` 换行。
- 飞书帮助中心《在文档中插入音视频等文件》（2026-05-18 页面版本）：视频预览右下角圆形拖点调整大小；网页端提供画中画入口。

## 图片验收

1. 悬浮或工具条内部聚焦时显示图片工具条，离开后隐藏。
2. 工具条支持裁剪、还原、说明、左/中/右对齐、预览、下载、块链接、分享与评论，所有按钮有中文可访问名称。
3. 选中图片后显示等比缩放拖点；完成拖动后将 `displayWidth` 写回节点，保存刷新后保持尺寸。
4. 进入裁剪后可拖动边和角；点击图片外部或按 Enter 完成，Esc 取消。
5. 图片说明中 Enter 完成，`Shift+Enter` 插入换行。
6. 双击或点击“预览图片”进入模态预览；Esc 关闭，Tab 不离开弹层，关闭后焦点回到来源。
7. 加载失败保留明确的失败面板和“重新加载”入口，不显示空白或伪成功。
8. 可直接按住图片本体拖动；超过 4px 后进入块拖拽，显示图片缩略图和精确插入线。
9. 图片可在正文块间、分栏之间及正文与分栏之间移动；点击、双击预览、裁剪和缩放不会误触拖拽。
10. 飞书不支持浮动图片和文字环绕，因此本地实现也不提供任意坐标浮动或环绕排版。

## 视频验收

1. 预览态显示标题、播放入口和原生播放控制。
2. 悬浮、选中或聚焦视频时显示右下角圆形缩放拖点。
3. 拖动时宽度限制在编辑区内并保持视频宽高比；结束后同时持久化 `displayWidth/displayHeight`。
4. 支持画中画的浏览器显示“画中画播放”按钮，并跟随进入/退出事件更新状态；失败时给出可见错误。
5. 全屏、下载、文本/卡片/预览切换、块链接、分享和评论继续由文件工具条提供。

## 自动化

- `mediaSizing.test.ts`：最小/最大宽度和宽高比。
- `media-file-blocks.spec.ts`：视频缩放、画中画入口、图片加载失败恢复。
- `image-crop.spec.ts`：图片裁剪确认与遮罩几何。
- `block-drag.spec.ts`：图片本体拖动、缩略预览和跨分栏落点。
