# MODAL-004 / 记录文本字段暂存编辑

## 用户目标

在记录详情中连续输入文本，不因每个字符产生一次保存和历史记录，并能撤销尚未确认的修改。

## 交互合同

- 输入期间只更新当前输入框草稿，不立即修改表格模型。
- Enter 或输入框失焦时提交一次；值未变化时不提交。
- Esc 放弃当前草稿、恢复最近一次已提交值，并保持记录弹窗打开。
- 切换记录时输入框同步新记录的最新字段值，不沿用上一条草稿。
- 点击一次“发送”只新增一条记录评论。

## 自动化

- `bitable-record-modal.spec.ts` 覆盖 Esc 撤销、Enter 单次提交、单条历史和评论不重复创建。
