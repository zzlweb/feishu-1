# SLASH-001 / Slash 触发、键盘与文件选择

## 触发合同

- `/` 只在文本块开头或空白字符后触发命令菜单。
- URL、文件路径、普通单词内部的 `/` 不触发。
- 查询中出现空白、换行或第二个 `/` 后关闭菜单。

## 键盘合同

- 主菜单使用上下方向键移动，Enter 执行，Esc 关闭。
- 有子菜单的项目使用 Enter 或右方向键打开。
- 子菜单使用方向键改变表格大小、栏数或当前模板/按钮类型，Enter 确认。
- Esc 或左方向键只关闭子菜单并回到主菜单，不执行主菜单项目。

## 文件选择合同

- 选择“图片”或“文件”时，在系统文件选择器返回有效文件之前不删除 Slash 命令文本。
- 用户取消系统文件选择器时，正文保持不变。
- 选中文件后再删除命令范围，并进入既有上传与失败块流程。
