# TABLE-001：普通表格行列重排与复杂结构保护

## 范围

- 简单矩形表格通过顶部列轨道或左侧行轨道拖动重排。
- 含 `rowspan`、`colspan` 或非矩形结构的表格不执行整行/整列重排。
- 结构保护不影响轨道选中、插入、删除、缩放、合并或拆分等其它操作。

## 交互契约

1. 按下轨道不立即改变选区；松开且未超过 4px 阈值时才选中对应整行或整列。
2. 简单表格超过阈值后进入拖动状态，并沿对应轴显示蓝色插入线。
3. 松开后移动完整行/列节点，保持单元格富文本、背景色、列宽和行高属性随节点移动；结束时清理整行/整列临时高亮，仅将文本光标放入移动后的单元格。
4. 合并表格的轨道使用 `not-allowed` 光标并在 `title` 中给出原因。
5. 用户仍尝试拖动时，只显示一次“请先拆分单元格”的警告；不显示插入线、不派发表格变更。
6. `pointercancel`、同位置放下与复杂表禁用路径都不得修改表格，也不得残留蓝色选区或浮动工具条。

## 自动化验收

- `client/tests/rich-table-docs.spec.ts`
  - 第一行拖到末尾后内容顺序正确，拖动线在结束后清理。
  - 同行内超过阈值但未形成有效移动时，内容不变且临时选区被清理。
  - 2×2 合并后轨道带禁用原因，尝试拖动显示警告，`rowspan`、内容与顺序保持不变。

## 已知边界

- 当前复杂表格采用结构保护，不尝试推导跨行/跨列单元格在重排后的新跨度。
- 保存刷新与 HTML/TSV 复杂粘贴分别由 FG-024、FG-026 收敛。
