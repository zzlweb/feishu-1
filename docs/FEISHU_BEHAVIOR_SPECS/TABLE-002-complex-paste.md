# TABLE-002：复杂 HTML/TSV 表格粘贴

## 范围

- 在正文中粘贴 HTML 表格时创建新的富文本表格。
- 在现有表格单元格或选区中粘贴 HTML/TSV 矩阵时写入目标范围。
- 支持 HTML `rowspan`、`colspan`、`th` 和安全的单元格背景色。

## 结构契约

1. HTML 源先转换为虚拟矩阵；合并根格保存内容、跨度和样式，被跨度覆盖的位置标记为 `covered`。
2. 正文粘贴会将虚拟矩阵重建为真实合并单元格，不为 `covered` 位置创建多余空格。
3. 表内粘贴保持目标表格结构，只向源矩阵的真实单元格写入内容。
4. `covered` 位置不代表空字符串，必须跳过，不能清空目标表格中对应的未触及单元格。
5. 源背景色通过浏览器 CSS 解析后再写入；无效 `bgcolor` 不进入编辑器样式。
6. 超出目标表格边界的数据裁剪；目标范围之外的内容和属性保持不变。
7. TSV 没有跨度语义，空字段仍是明确写入的空单元格。

## 自动化验收

- `client/tests/rich-table-docs.spec.ts`
  - 正文粘贴带 rowspan、colspan、th、bgcolor 的 HTML 表，验证节点数量、跨度与颜色。
  - 向 3×3 目标表粘贴 2×2 合并区域，验证覆盖位原有文本未被清空，同时真实源格和背景被写入。
