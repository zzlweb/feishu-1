# TABLE-004 单元格块柄与菜单锚定

## 用户目标

在表格单元格内编辑待办、列表或其它块时，左侧块柄和块菜单始终属于当前内容，不侵入表格，也不会在滚动或窗口变化后漂走。

## 行为契约

1. 首列单元格块柄的右边缘必须位于表格左边界之外，并保留可见间距。
2. 块柄按自身真实宽度向左定位，不能使用固定宽度假设；待办和列表图标不得侵入单元格。
3. 块菜单以真实块柄 DOM 为持续锚点，而不是只保存打开瞬间的一组坐标。
4. 菜单优先显示在块柄左侧，纵向覆盖块柄中心；窗口变化和文档滚动后继续重新计算。
5. 单元格内的插入按钮、块柄和表格整体块柄互斥显示，不形成重叠的操作入口。

## 自动化证据

- `client/tests/rich-table-docs.spec.ts` 验证首列块柄不侵入表格、菜单位于块柄左侧且纵向仍与块柄相连。
