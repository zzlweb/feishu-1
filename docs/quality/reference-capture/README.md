## 采集规范

1. 使用可公开访问或已获授权的飞书样本，不记录账号、组织、评论人或文件隐私信息。
2. 桌面基准为 1440×900；响应式相关流程补 1024×768、768×1024、390×844。
3. 文件名使用 `<REF-ID>-<state>-<viewport>.png`，例如 `REF-GRID-01-readonly-1440x900.png`。
4. 每个编号同时记录操作步骤、观察结果、产品应复刻的行为，以及明确不复刻的品牌/内部实现细节。
5. 不得以占位图或口头描述标记“已采集”；只有真实截图和记录齐全才更新状态。
6. 甘特图不在产品范围内，不采集、不比较、不进入发布门禁。
